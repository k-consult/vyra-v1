The Cockpit (Controlled Governance)

The one seat with a human in it. Everything above reasons on its own; nothing commits until someone here says so.

Decision {
  type: "control-recommendation"
  rationale: "…"
  confidence: 0.82
  status: PENDING
}
Approve

Writes a real node — Control, Finding, Risk, or the full Assurance chain — attributed to the reviewer.

Reject

status → REJECTED, optional note. No graph mutation — the loop stops here, cleanly.

The OS Building Blocks
Shared memory
The same graph every stage above reads and writes.
Continuous observation
Layer 1 never stops polling — nobody has to ask.
Governed autonomy
Every Reason ends at Govern, never a direct write.
Traceability
Layer 2 is structural, always on — not a report someone wrote.
Full-loop coverage
Four agents span all four stages — nothing observed twice.
Open

The control plane closes the loop within one agent's lane — not yet across agents. An approved Risk doesn't currently retrigger control-intelligence to reconsider a Control. That's Scenario Simulation, and it's still unscoped: no working definition yet of what a "scenario" is in this domain.
